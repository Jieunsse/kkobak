# 초대 링크 웹 화면은 앱(Expo)이 아니라 소개 페이지(Next.js)에서 만든다

초대 링크를 카카오톡에 붙이면 미리보기 카드에 그룹 이름과 규칙 요약이 보여야 사람들이 누른다. 이 카드는 서버가 HTML에 미리보기 정보를 넣어야 만들어진다. 그래서 초대 웹 화면은 서버 렌더링이 되는 `landing/`(Next.js)에 두고, 처음 정했던 Expo 웹은 쓰지 않는다(2026-11-27). 링크를 누르면 앱이 바로 열리는 유니버설 링크는 운영 중에 붙이고, 첫 버전은 웹 화면의 "앱에서 열기" 버튼과 스토어 이동으로 대신한다.
