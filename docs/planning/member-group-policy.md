# 회원과 그룹 참여 정책 (1주차 범위)

마지막 수정: 2026-11-27
상태: 모든 항목 확정 (2026-11-27 사용자 승인)
관련 문서: [그룹 규칙 명세](rules-spec.md)(그룹 운영 규칙), [안전 정책](safety-policy.md)(신고·차단), [알림 정책](notification-policy.md)(알림), [엣지 케이스 정책](edge-cases.md)(경계 상황), 용어는 [용어집](../../GLOSSARY.md)

이 문서는 로그인, 계정, 그룹 만들기, 초대, 참여, 내보내기, 그룹 시작을 다룬다. 인증, 판정, 장부, 정산은 [그룹 규칙 명세](rules-spec.md)에 있다.

## 0. 역할과 권한 (확정, 2026-11-27)
누가 무엇을 할 수 있는지 한 표로 정리한다. 첫 버전에서 정산 담당은 그룹장이다. 운영자는 꼬박을 운영하는 사람이다.

| 할 수 있는 일 | 멤버 | 그룹장 | 정산 담당 | 운영자 |
|---|---|---|---|---|
| 인증하기, 쉬는 날 선언, 이의 제기 | O | O | O | |
| 그룹원 확인 투표 (본인 인증 제외) | O | O | O | |
| 그룹원 확인이 정해지지 않았을 때 결정 | | O | | |
| 규칙 바꾸기, 초대 링크 새로 만들기 | | O | | |
| 멤버 내보내기, 그룹장 넘기기 | | O | | |
| 그룹 지우기 (모집 중일 때만) | | O | | |
| 보증금 받음 표시, 보증금 넘겨받음 표시 | | | O | |
| 정산 완료 표시 | 정산 담당에게서 받을 돈이 있을 때 | | 멤버에게서 받을 돈이 있을 때 | |
| 나가기, 차단, 신고 | O | O (종료 뒤 정산 전에는 나가기 불가) | O | |
| 판정 정정, 장애 보상, 부적절 사진 이의 처리, 경고·정지 | | | | O |

- 그룹장도 멤버라서 멤버가 할 수 있는 일을 모두 한다.
- 운영자는 그룹 규칙을 바꾸거나 판정 투표에 참여하지 않는다. 판정을 바꾸는 것은 꼬박의 잘못을 바로잡을 때뿐이다(판정 정정, 장애 보상).
- 정산 완료 표시는 돈을 받는 사람이 한다. 자세한 규칙은 [그룹 규칙 명세](rules-spec.md) 7-6절(보증금과 정산 표시)에 있다.

## 1. 회원

### 1-1. 로그인과 받는 정보
- 카카오 로그인과 애플 로그인을 쓴다.
- 받는 정보는 닉네임과 프로필 사진뿐이다. 이메일, 실명, 전화번호는 받지 않는다.
- 닉네임은 그룹 안에서 다른 멤버에게 보이는 이름이다. 실명은 어디에도 공개하지 않는다.
- 닉네임 규칙 (2026-11-27 확정):
  - 2~10자. 한글, 영문, 숫자만 쓴다. 섞어 써도 된다. 공백과 특수문자는 쓸 수 없다.
  - 금지어가 들어 있으면 저장하지 않고 이유를 보여 준다([안전 정책](safety-policy.md) 1장).
  - 다른 그룹 사람과는 같아도 된다. 같은 그룹 안에서는 겹칠 수 없다([엣지 케이스 정책](edge-cases.md) A5: 사칭 방지).
  - 가입할 때 카카오·애플 닉네임을 채워 두고, 규칙에 맞지 않으면 고치게 한다.
  - 바꾸기는 하루 1번까지다. 바꾸면 내가 속한 그룹의 변경 이력에 남는다.
- 프로필 사진은 카카오·애플 프로필 사진과 꼬박 기본 이미지(도장) 중에서 고른다. 사진을 직접 올리는 기능은 없다. 사용자가 올리는 콘텐츠를 줄여 부적절한 사진 위험을 줄인다. (2026-11-27 확정)
- 로그인 유지 (2026-11-27 확정):
  - 앱을 30일 동안 한 번도 열지 않으면 다시 로그인한다.
  - 로그인할 수 있는 기기 수는 제한하지 않는다.
  - 로그아웃은 그 기기에서만 된다.
- 꼬박은 돈을 옮기지 않으므로 실명과 연락처가 필요 없다. 받는 정보를 줄여서 개인정보 위험을 줄인다.

### 1-2. 가입 조건
- 만 14세 이상만 가입할 수 있다. 가입할 때 "만 14세 이상입니다"를 체크한다.
- 이용약관과 개인정보처리방침에 동의해야 가입된다.
- 만 14세 미만 가입자를 위한 법정대리인 동의 절차는 만들지 않는다.

### 1-3. 계정 삭제
- 앱 안에서 계정을 삭제할 수 있다.
- 진행 중인 그룹이 있으면 계정을 지우기 전에 그 그룹에서 먼저 나가게 처리한다. 돈은 [그룹 규칙 명세](rules-spec.md) 6-3절(중간 탈퇴 시 돈 처리)대로 처리한다.
- 삭제하면 닉네임과 프로필 사진을 지운다. 장부와 판정 기록은 지우지 않고, 이름만 "탈퇴한 멤버"로 바꿔 남긴다. 남은 멤버의 정산이 맞아야 하기 때문이다.
- 인증 사진은 [그룹 규칙 명세](rules-spec.md) 4-1절(사진 보관)대로 올린 지 30일 뒤에 지운다. 계정을 삭제하면 그 시점에 남아 있는 사진도 바로 지운다.
- 판정, 장부, 정산표 기록은 그룹 종료 뒤 1년 보관하고 지운다([엣지 케이스 정책](edge-cases.md) E7: 종료된 그룹의 기록 보관 기간). 영구 정지 기록은 계정을 지워도 로그인 식별값과 함께 보관한다([엣지 케이스 정책](edge-cases.md) A2: 영구 정지된 사람이 다시 가입할 때). 모든 데이터의 보관 기간은 [운영 정책](operations-policy.md) 5장에 한 표로 있다.

### 1-4. 동의와 약관 (2026-11-27 확정)
| 동의 | 필수 여부 | 언제 받나 |
|---|---|---|
| 이용약관 | 필수 | 가입할 때 |
| 개인정보처리방침 | 필수 | 가입할 때 |
| 만 14세 이상 | 필수 | 가입할 때 |
| 마케팅 알림(이벤트, 새 기능 소식) | 선택 | 가입할 때, 또는 설정에서 언제든 |
| 푸시 알림 권한 | 휴대폰 권한 | 첫 그룹에 참여한 직후([알림 정책](notification-policy.md) 3장) |

- 동의한 약관 버전과 동의 시각을 기록한다.
- 약관이나 개인정보처리방침이 중요하게 바뀌면(받는 정보, 보관 기간, 책임 범위가 바뀔 때) 앱을 열 때 다시 동의를 받는다. 동의하지 않으면 계정 삭제로 안내한다.
- 사소하게 바뀌면(문구 정리 등) 시행 7일 전에 앱 공지로만 알린다.
- 마케팅 알림 동의는 2년마다 다시 확인한다(정보통신망법). 다시 동의하지 않으면 마케팅 알림을 끈다.
- 마케팅 알림은 밤 9시부터 아침 8시까지 보내지 않는다.
- 규칙 카드에 동의하고 그룹에 참여한 기록(그때의 규칙 버전, 시각)도 남긴다. 돈 다툼이 생기면 이 기록을 보여 준다.

## 2. 그룹 참여

### 2-1. 한 사람이 들어갈 수 있는 그룹 수
- 「모집 중」과 「진행 중」 그룹을 합쳐 동시에 3개까지 들어갈 수 있다.
- 이미 3개에 들어가 있으면 그룹을 더 만들거나 참여할 수 없다. 이때 화면에 지금 들어간 그룹 목록을 보여 준다.
- 이 숫자는 운영하면서 데이터를 보고 늘린다.

### 2-2. 초대 링크
- 그룹마다 초대 링크가 하나 있고, 여러 번 쓸 수 있다.
- 링크에는 만료 시간이 없다. 모집글에 붙여 두는 링크라서 모집 중에 막히면 안 되기 때문이다.
- 그룹장이 링크를 새로 만들면 이전 링크는 바로 막힌다.
- 초대 웹 화면은 소개 페이지(Next.js)에 만든다. 카카오톡 미리보기 카드에 그룹 이름과 규칙 요약이 보인다([ADR-0002](../adr/0002-invite-page-in-landing.md): 초대 화면을 소개 페이지에 두기로 한 결정).
- 앱이 깔린 사람은 웹 화면의 "앱에서 열기" 버튼으로 앱을 연다. 앱이 없으면 스토어로 보낸다.
- 링크를 연 사람은 앱이 없어도 웹에서 규칙 카드(목표, 마감, 벌금, 보증금, 벌금 사용 방식, 탈퇴 시 돈 처리, 기간, 인원)와 멤버 수를 본다.
- 참여 버튼을 누르면 로그인 화면이 나온다. 인증은 앱에서 하므로 참여한 뒤에는 앱을 설치하라고 안내한다.
- 아래 경우에는 참여할 수 없다는 화면을 보여 주고 이유를 적는다.
  - 종료일까지 7일이 안 남았다([엣지 케이스 정책](edge-cases.md) J1: 종료 7일 전부터 참여 불가)
  - 이번 기간에 스스로 나간 적이 있다([엣지 케이스 정책](edge-cases.md) J2: 스스로 나간 사람은 같은 기간에 다시 참여 불가)
  - 그룹장이 나를 차단했다([안전 정책](safety-policy.md) 3장: 차단). 이유는 "참여할 수 없는 그룹이에요"로만 보여 준다
  - 인원이 꽉 찼다
  - 그룹이 끝났다
  - 링크가 새로 만들어져 막혔다
  - 이미 3개 그룹에 들어가 있다
  - 이미 이 그룹의 멤버다 (이때는 그룹 화면으로 보낸다)

### 2-3. 그룹장이 멤버 내보내기
- 그룹장은 멤버를 내보낼 수 있다. 그룹장 자신은 내보낼 수 없다.
- 돈 처리: 그룹이 고른 탈퇴 방식과 상관없이 항상 "벌금 빼고 보증금 돌려주기"로 처리한다([그룹 규칙 명세](rules-spec.md) 6-3절, 중간 탈퇴 시 돈 처리). 그룹장이 멤버를 내보내서 보증금을 가져가지 못하게 하려는 것이다. (2026-11-27 고침)
- 그룹장은 내보낼 때 이유를 적을 수 있다. 적지 않아도 된다.
- 내보낸 기록(누가, 언제, 누구를)은 그룹 안에 남는다. 멤버 모두가 이 기록을 볼 수 있다.
- 내보내진 사람은 같은 링크로 다시 참여할 수 없다. 그룹장이 링크를 새로 만들어도 마찬가지다.
- 내보내진 사람이 다른 계정으로 다시 참여하는 것은 막지 않는다. 꼬박 계정은 카카오나 애플 계정 하나에 묶여 있어서 새로 만들기 번거롭기 때문이다. 그룹장은 다시 내보낼 수 있다.

## 3. 그룹 상태

```
모집 중 ──(시작일, 멤버 2명 이상)──▶ 진행 중 ──(종료일 다음 날)──▶ 종료
   │
   └─(시작일, 멤버 2명 미만)──▶ 모집 중 그대로 + 그룹장에게 시작일을 미루라는 알림
```

| 상태 | 참여 | 규칙 수정 | 판정 |
|---|---|---|---|
| 모집 중 | 가능 | 모든 규칙을 바꿀 수 있다. 바뀌면 이미 참여한 멤버에게 알림이 간다 | 없음 |
| 진행 중 | 가능 (중간 합류, [그룹 규칙 명세](rules-spec.md) 6-1절) | 돈 규칙 3개(돈 방식, 벌금 사용 방식, 탈퇴 시 돈 처리)는 바꿀 수 없다. 나머지는 3일 뒤 인증일부터 적용한다([그룹 규칙 명세](rules-spec.md) 2장, 그룹 규칙 설정. [엣지 케이스 정책](edge-cases.md) T1: "3일 뒤"는 바꾼 시각에서 72시간 뒤 처음 시작하는 인증일) | 있음 |
| 종료 | 불가 | 불가 | 정산표가 나온다 |

- 시작일에 멤버가 2명 미만이고 그 뒤 7일 안에 그룹장이 시작일을 미루지 않으면, 그룹을 자동으로 지우고 멤버에게 알린다. 시작하지 못한 그룹이 한 사람당 3개 제한을 계속 차지하지 않게 하려는 것이다.
- 「모집 중」에 그룹장이 나가거나 계정을 지우면, 「진행 중」일 때와 똑같이 가장 먼저 참여한 멤버가 그룹장이 된다([그룹 규칙 명세](rules-spec.md) 6-2절, 그룹장이 나갈 때). 남은 멤버가 없으면 그룹을 지운다.
- 한 사람이 하루에 만들 수 있는 그룹은 3개까지다. 만들었다가 지운 그룹도 센다. 그룹을 반복해서 만들고 지우며 초대 알림을 보내는 것을 막는다.
- 그룹장은 시작일 전에 그룹을 지울 수 있다. 지우면 멤버에게 알림이 간다. 진행 중인 그룹은 지울 수 없다.
- 「모집 중」에 규칙이 바뀌어도 멤버는 다시 동의하지 않는다. 대신 바뀐 내용을 알림으로 알린다. 멤버는 원하면 벌금 없이 나갈 수 있다(시작 전이라 장부가 없다).
