# 운영 정책: 공개 범위, 공유, 문의, 남용 제한, 업데이트, 입력·표시, 운영 도구

마지막 수정: 2026-11-27
상태: 모든 항목 확정 (2026-11-27 사용자 승인)
관련 문서: [회원·참여 정책](member-group-policy.md), [안전 정책](safety-policy.md)(신고·차단·처리 기한), [그룹 규칙 명세](rules-spec.md)(판정·정산), 용어는 [용어집](../../GLOSSARY.md)

이 문서는 누가 무엇을 볼 수 있는지, 밖으로 무엇을 공유하는지, 문의를 어떻게 받는지, 남용을 어떻게 막는지, 데이터를 얼마나 보관하는지, 앱 업데이트와 점검을 어떻게 하는지 정한다.

## 1. 공개 범위

### 1-1. 인증 사진
- 같은 그룹 멤버만 본다. 그룹 밖 사람은 볼 수 없다.
- 오늘 사진은 내가 오늘 인증하거나 쉬는 날을 선언한 뒤에 보인다. 누가 인증했는지(꼬박이·깜박이)는 그 전에도 보인다([기획 문서](planning.md) 4-3절에서 정한 규칙).
- 지난 날 사진은 원본이 지워질 때까지(올린 지 30일) 언제든 본다.
- 앱 안에 사진 저장 버튼은 두지 않는다. 화면 캡처는 막지 않는다.
- 내가 차단한 사람의 사진은 보이지 않는다([안전 정책](safety-policy.md) 3장).

### 1-2. 멤버끼리의 반응
- 첫 버전에는 응원, 댓글, 반응 기능이 없다. 그룹은 이미 카카오톡 단톡방에서 이야기한다.
- 결석 다음 날 복귀율([기능 가설](hypotheses.md) H4)이 기준선(60%)에 못 미치면, 꼬박이에게 응원 하나를 누르는 기능을 검토한다.

### 1-3. 초대 웹 화면 (로그인하지 않은 사람)
- 보여 주는 것: 규칙 카드, 그룹 이름, 그룹장 닉네임, 멤버 수
- 보여 주지 않는 것: 멤버 닉네임 목록, 프로필 사진, 인증 사진, 판정, 장부
- 검색 엔진에 나오지 않게 막는다. 링크를 받은 사람만 보면 된다.

### 1-4. 지난 그룹
- 종료된 그룹은 "지난 그룹" 목록에서 1년 동안 장부와 정산표를 볼 수 있다. 기록 보관 기간(5장)과 같다.
- 지난 그룹은 한 사람이 들어갈 수 있는 그룹 3개 제한에 세지 않는다.

## 2. 공유

### 2-1. 인증 카드
| 넣는 것 | 넣지 않는 것 |
|---|---|
| 내 연속 인증 일수, 도장, 오늘 그룹 인증 현황(예: 5명 중 4명) | 다른 멤버의 닉네임, 프로필 사진, 인증 사진 |
| 내 인증 사진 (내가 고를 때만) | 벌금 금액, 장부 |
| 그룹 이름 (내가 고를 때만) | |

### 2-2. 한 주 인증 기록 격자
- 7일 × 멤버 칸에 인증 여부만 칠한다. 내 줄만 "나"로 표시하고, 다른 멤버는 닉네임 없이 칸만 보인다.
- 벌금 금액은 넣지 않는다.

### 2-3. 공유 링크
- 공유 이미지에 꼬박 소개 페이지 링크를 붙인다. 링크에는 공유 출처 표시(어떤 카드에서 왔는지)를 붙여, 공유로 들어온 사람 수를 PostHog로 잰다([기능 가설](hypotheses.md) H6).
- 출처 표시에는 개인정보를 넣지 않는다. 내부 번호만 쓴다.

## 3. 문의 응대

### 3-1. 문의 받는 곳과 종류
- 앱 안 "문의하기"에서 받는다. 운영자 이메일은 설정 화면과 스토어 페이지에 둔다.
- 문의할 때 종류를 하나 고른다: 계정·로그인, 인증·판정, 정산·돈, 신고·안전, 오류, 기타.
- 신고는 문의가 아니라 신고 버튼으로 받는다([안전 정책](safety-policy.md) 2장).

### 3-2. 답하는 범위
- 꼬박이 답하는 것: 계정 복구, 판정이 규칙대로 되었는지, 정산표 계산, 오류, 신고 결과
- 꼬박이 답하지 않는 것: 멤버끼리 돈을 주고받는 일. 이때는 기록(장부, 규칙 변경 이력, 보증금 받음·정산 완료 표시 기록)을 보는 방법만 안내한다. 꼬박은 돈 거래 당사자가 아니기 때문이다([그룹 규칙 명세](rules-spec.md) 맨 앞, 앱의 책임 범위).
- 판정에 대한 불만은 먼저 이의 제기로 안내한다. 꼬박 잘못(장애, 버그)이 확인되면 운영자가 바로잡는다.

### 3-3. 공개와 기한
- 문의와 답은 문의한 사람과 운영자만 본다. 공개 Q&A는 두지 않는다.
- 자주 묻는 질문은 앱 안 도움말에 모은다.
- 첫 답 기한은 2영업일이다([안전 정책](safety-policy.md) 5장).

## 4. 남용 제한
아래 한도를 넘으면 그날은 막고 이유를 보여 준다. 한도는 한국 시간 자정에 다시 채워진다(이의 제기는 월요일 자정).

| 행동 | 한도 | 막는 이유 |
|---|---|---|
| 한 인증일에 올리는 사진 | 그룹마다 10장 | 사진 저장 비용과 AI 확인 비용을 막는다 |
| 이의 제기 | 한 그룹에서 일주일에 3번 | 그룹원 확인 요청이 쏟아지는 것을 막는다. 한 판정에는 이의를 한 번만 낼 수 있다([엣지 케이스 정책](edge-cases.md) D2) |
| 신고 | 하루 10건 | 신고 남발을 막는다 |
| 초대 링크 새로 만들기 | 그룹마다 하루 5번 | 링크를 계속 바꿔 멤버를 헷갈리게 하는 것을 막는다 |
| 닉네임 바꾸기 | 하루 1번 | 사칭을 막는다 |
| 그룹 만들기 | 하루 3개 (지운 그룹도 센다) | 반복 생성으로 초대 알림을 보내는 것을 막는다 |

- 한도를 반복해서 넘는 사람은 운영자가 확인하고, 필요하면 [안전 정책](safety-policy.md) 4장의 조치를 한다.

## 5. 데이터 보관
데이터 보관 기간 표는 [개인정보 정책](personal-data-policy.md) 3장으로 옮겼다.

## 6. 앱 업데이트와 점검
- 서버가 최소 앱 버전을 정한다. 앱이 그보다 낮으면 업데이트 화면만 보여 준다.
- 최소 버전은 판정, 장부, 정산 계산에 영향을 주는 변경일 때만 올린다. 그 밖의 업데이트는 권하기만 한다.
- 계획된 점검은 새벽 3시부터 5시 사이에만 한다.
- 점검은 하루 전에 앱 첫 화면 공지로 알린다.
- 점검 시간 안에 마감(마감 + 유예)이 있는 그룹의 그날 판정은 꼬박 장애와 같이 쉬는 날로 바꾸고, 쉬는 날 횟수는 쓰지 않은 것으로 친다([그룹 규칙 명세](rules-spec.md) 9장).
- 지원하는 휴대폰 운영체제는 Expo가 지원하는 최소 버전을 따른다. 그보다 낮은 기기에서는 스토어에서 설치되지 않는다. (권장, 2026-11-27)

## 7. 입력과 표시 규칙 (권장, 2026-11-27)

### 7-1. 입력칸
| 칸 | 글자 수 | 쓸 수 있는 문자 |
|---|---|---|
| 닉네임 | 2~10자 | 한글, 영문, 숫자 ([회원·참여 정책](member-group-policy.md) 1-1절) |
| 그룹 이름 | 2~20자 | 한글, 영문, 숫자, 공백, 마침표·쉼표·하이픈 |
| 인증 기준 문장 | 100자 이하 | 이모지 빼고 모두 |
| 내보내기 이유 | 100자 이하 | 이모지 빼고 모두 |
| 문의 내용 | 1,000자 이하 | 모두 |

- 모든 입력칸은 앞뒤 공백을 지우고 저장한다. 공백이 두 번 이상 이어지면 하나로 줄인다.
- 같은 그룹 안 닉네임 중복은 영문 대소문자를 구분하지 않고 판단한다(Kim과 kim은 같은 닉네임).
- 금지어 검사는 공백과 특수문자를 뺀 글자로 한다.

### 7-2. 시간과 숫자
- 서버는 모든 시각을 UTC로 저장하고, 화면에는 한국 시간으로 보여 준다.
- 날짜와 시각은 "11월 27일 (목) 23:59" 형식으로 보여 준다. 연도가 다를 때만 연도를 붙인다.
- 금액은 원 단위 정수다. 나누어떨어지지 않는 나머지는 정산 담당 몫으로 남긴다([그룹 규칙 명세](rules-spec.md) 7-3절). 화면에는 "2,000원"처럼 쉼표를 찍는다.

### 7-3. 화면 문구
- 모든 문구는 해요체로 쓴다.
- 오류 문구는 무엇이 안 됐는지와 다음에 할 일을 함께 쓴다. 예: "사진을 올리지 못했어요. 연결을 확인하고 다시 올려 주세요."
- 사용자를 탓하는 말을 쓰지 않는다. 예: "잘못 입력하셨습니다" 대신 "닉네임은 2~10자로 써 주세요".

## 8. 인증 사진 파일 (권장, 2026-11-27)
- 앱 카메라로 찍은 사진만 올린다([그룹 규칙 명세](rules-spec.md) 4-1절).
- 앱이 긴 변 1,600픽셀로 줄이고 JPEG로 바꿔 올린다. 한 장의 최대 크기는 2MB다.
- 올리기 전에 위치 정보와 촬영 정보를 지운다([개인정보 정책](personal-data-policy.md) 1장).
- 사진의 권리는 찍은 사람에게 있다. 꼬박은 판정과 그룹 안 공개, 그리고 본인이 고른 공유 카드에만 쓴다.

## 9. 목록 정렬 (권장, 2026-11-27)
| 목록 | 순서 |
|---|---|
| 내 그룹 | 오늘 마감이 가까운 그룹 먼저. 오늘 이미 인증한 그룹은 뒤로 |
| 그룹 현황의 멤버 | 아직 인증하지 않은 멤버(깜박이) 먼저, 그다음 인증한 멤버(꼬박이)를 인증 시각 순으로 |
| 지난 그룹 | 종료일이 최근인 그룹 먼저 |
| 알림 | 최근 것 먼저 |

## 10. AI 판정 알리기 (권장, 2026-11-27)
- 인증 화면과 판정 결과에 "AI가 먼저 확인해요"를 표시한다.
- AI가 거절하거나 애매하다고 하면, 이의 제기와 그룹원 확인으로 사람이 다시 볼 수 있다고 함께 안내한다.
- 이용약관에 AI가 판정을 돕는다는 사실과, 최종 판정은 이의 제기 절차를 거쳐 정해진다는 사실을 적는다.

## 11. 요청 제한과 악성 민원 (권장, 2026-11-27)
- 한 회원이 서버에 보내는 요청은 1분에 120번까지다. 넘으면 1분 동안 막고 "잠시 후 다시 시도해 주세요"를 보여 준다. 로그인하지 않은 요청은 IP 주소마다 1분에 60번까지다.
- 초대 웹 화면은 초대 코드를 무작위로 맞혀 보는 것을 막기 위해, 같은 IP에서 없는 코드를 1분에 10번 넘게 열면 10분 동안 막는다.
- 같은 내용의 문의를 하루 3번 넘게 보내거나 욕설이 담긴 문의는 답을 멈추고 한 번 안내한다. 계속되면 [안전 정책](safety-policy.md) 4장의 조치를 한다.

## 12. 운영 도구와 내부 계정 (권장, 2026-11-27)
- 운영자는 한 명이고 권한 등급은 하나다.
- 운영 도구(어드민)는 앱과 분리된 주소에 두고, 로그인할 때 2단계 인증을 거친다.
- 운영자가 회원 정보를 열거나 판정·장부를 고치면 누가, 언제, 무엇을, 왜 했는지 운영 기록에 남는다([정책 운영 원칙](meta-policy.md) 5장).
- 운영자와 개발용 테스트 계정은 "내부 계정"으로 표시한다. 내부 계정이 있는 그룹은 가설 판정과 지표에서 뺀다.
- 지인 테스트 그룹(3주차부터)은 지표에 넣되 "지인 테스트"로 표시해서 따로도 볼 수 있게 한다.

## 13. 서비스 종료 (권장, 2026-11-27)
- 기능 하나를 없앨 때는 30일 전에 알린다.
- 서비스 전체를 끝낼 때는 30일 전에 알리고, 진행 중 그룹에 새 기간 시작을 막는다. 종료일까지 장부와 정산표를 이미지로 저장할 수 있게 한다. 꼬박은 유료 기능이 없어서 환불할 돈은 없다.

## 14. 언어와 지역 (권장, 2026-11-27)
- 한국어만 지원한다. 앱스토어와 플레이스토어에는 대한민국에만 출시한다.
- 금액 단위는 원, 시간은 한국 시간이다.
