# 알림 정책

마지막 수정: 2026-11-27
상태: 확정 (2026-11-27 사용자 승인)

## 0. 알림 채널 (권장, 2026-11-27)
- 휴대폰 푸시와 앱 안 알림 목록 두 가지만 쓴다. 이메일과 문자는 보내지 않는다(이메일과 전화번호를 받지 않기 때문이다).
- 모든 푸시는 앱 안 알림 목록에도 남는다. 알림 목록은 30일 동안 보관한다.
- 마케팅 알림은 제목 앞에 "(광고)"를 붙이고, 끄는 방법을 본문 끝에 적는다(정보통신망법).

## 1. 알림 종류
| 알림 | 언제 | 누구에게 | 끌 수 있나 |
|---|---|---|---|
| 마감 전 알림 | 마감 2시간 전 | 아직 인증하지 않았고 쉬는 날도 선언하지 않은 멤버 | 예 |
| 판정 결과 | 임시 판정이 결석이나 지각일 때만 | 본인 | 예 |
| 복귀 | 결석 다음 인증일에 인증했을 때 | 그룹 멤버 | 예 |
| 그룹원 확인 요청 | AI가 "애매"로 판단했거나 이의 제기가 들어왔을 때 | 확인할 멤버 | 아니오 |
| 이의 제기 결과 | 확인이 끝났을 때 | 본인 | 아니오 |
| 규칙 변경 | 그룹장이 규칙을 바꿨을 때 | 멤버 모두 | 아니오 |
| 내보내기 | 그룹장이 내보냈을 때 | 내보내진 사람 | 아니오 |
| 그룹 시작·종료·자동 삭제·시작일 미루기 요청 | 상태가 바뀔 때 | 멤버 모두, 미루기 요청은 그룹장 | 아니오 |
| 새 멤버 참여 | 새 멤버가 참여했을 때 | 그룹장 | 예 |
| 정산 | 모든 판정이 확정되어 확정 정산표가 나왔을 때 보낸다. 정산이 안 끝났으면 3일 뒤에 한 번 더 보낸다 | 멤버 모두 | 예 |
| 마케팅 알림(이벤트, 새 기능 소식) | 운영자가 보낼 때. 밤 9시~아침 8시에는 보내지 않는다 | 마케팅 알림에 동의한 사람([회원·참여 정책](member-group-policy.md) 1-4절) | 예 |
| 점검 공지 | 계획된 점검 하루 전([운영 정책](operations-policy.md) 6장) | 모두 | 아니오 |
| 신고 조치 결과, 운영자 조치 | 조치했을 때 | 본인 | 아니오 |
| 장애 보상 | 장애로 판정이 바뀌었을 때 | 영향받은 멤버 | 아니오 |

돈, 권리, 판정에 관련된 알림은 끌 수 없다.

## 2. 보내는 규칙
- 밤 9시부터 아침 8시까지(한국 시간)는 끌 수 있는 알림을 보내지 않고 아침 8시에 모아 보낸다.
  - 마감 전 알림은 예외다. 그룹 마감이 이 시간 안에 있으면 그대로 보낸다.
- 같은 그룹의 같은 종류 알림이 1시간 안에 여러 번 생기면 하나로 묶는다(예: 새 멤버 3명 참여).
- 마감 전 알림은 인증일마다 한 번만 보낸다.
- 알림 문구는 꼬박의 말투(재치 있는 총무)를 따른다. 단, 끌 수 없는 알림은 장난 없이 사실만 쓴다.

## 3. 설정
- 끌 수 있는 알림은 종류마다 켜고 끌 수 있다.
- 그룹마다 마감 전 알림을 끌 수 있다.
- 휴대폰 설정에서 꼬박 알림 권한을 껐으면, 앱 첫 화면에 "알림이 꺼져 있어 마감을 놓칠 수 있어요"를 한 번 보여 준다.
- 푸시 알림 권한은 첫 그룹에 참여한 직후에 묻는다. 가입하자마자 묻지 않는다. 사람들은 알림이 왜 필요한지 알 때 더 잘 허락하기 때문이다.
