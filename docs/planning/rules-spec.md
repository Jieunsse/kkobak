# 꼬박 그룹 규칙 명세 (첫 버전)

마지막 수정: 2026-11-27
근거 문서: [planning.md](planning.md) 2-2장(그룹 규칙 13개), 4-3장(충돌 해결), 5장(결정 기록)

상태: 이 문서의 모든 규칙은 확정이다 (2026-11-27 사용자 승인). 첫 버전에서 다루지 않는 것은 10장에 따로 적었다.

꼬박은 돈을 맡거나 옮기지 않는다. 이 문서의 모든 금액은 계산해서 보여 주는 숫자다. 실제 돈은 그룹이 앱 밖에서 주고받는다. (확정)

## 1. 용어
용어의 원본은 레포 루트 [GLOSSARY.md](../../GLOSSARY.md)다. 이 문서는 그 용어를 그대로 쓴다.

---|---|
| 그룹 | 같은 목표와 규칙을 공유하는 사람들의 모임이다. 시작일과 종료일이 있다 |
| 그룹장 | 그룹을 만든 사람이다. 규칙을 바꾸고 정산 완료를 표시한다 |
| 멤버 | 그룹에 참여한 사람이다. 그룹장도 멤버다 |
| 인증일 | 판정의 단위가 되는 하루다. 마감 시각에 끝난다 |
| 인증 | 앱 카메라로 찍어 올린 사진 한 장이다 |
| 판정 | 멤버의 인증일 하나에 대한 결과다. 정상, 지각, 결석, 쉬는 날 중 하나다 |
| 이의 제기 | 판정 결과에 대해 본인이 다시 확인을 요청하는 것이다 |
| 장부 | 확정된 판정에서 나온 벌금 기록이다 |
| 정산표 | 그룹이 끝날 때 멤버마다 받을 돈이나 낼 돈을 계산한 표다 |
| 정산 담당 | 그룹의 돈을 실제로 맡은 사람이다. 첫 버전에서는 그룹장이다 |
| 꼬박이, 깜박이 | 오늘 인증한 멤버와 아직 안 한 멤버를 화면에서 부르는 이름이다 |

## 2. 그룹 규칙 설정
그룹장이 그룹을 만들 때 아래를 정한다. 초대 링크의 규칙 카드에 모두 보인다. 초대받은 사람은 규칙 카드를 본 뒤에 참여 버튼을 누를 수 있다. (확정)

| 항목 | 선택지 | 기본값 | 상태 |
|---|---|---|---|
| 목표 템플릿 | 공부, 독서, 운동 | 없음 (필수) | 확정 |
| 판정 단위 | 매일 / 주 N회 (N은 1~6) | 매일 | 확정 |
| 마감 시각 | 00:00~23:59 사이 아무 때나 | 23:59 | 확정 |
| 지각 유예 시간 | 0분, 30분, 1시간, 2시간 | 1시간 | 확정 |
| 결석 벌금 | 0원~10,000원, 100원 단위 | 2,000원 | 확정 |
| 지각 벌금 | 0원~결석 벌금 이하 | 결석 벌금의 절반 | 확정 |
| 쉬는 날 | 한 달 0~3회 | 2회 | 확정 |
| 돈 방식 | 보증금 없음 / 보증금 있음 (금액 입력) | 보증금 없음 | 확정 |
| 벌금 사용 방식 | 꼬박이 몫으로 나누기 / 공동 비용으로 쓰기 / 전원에게 똑같이 돌려주기 | 없음 (필수) | 확정 |
| 중간 탈퇴 시 돈 처리 | 4장 탈퇴 규칙 참고 | 없음 (필수) | 확정 |
| 기간 | 시작일, 종료일 (1~12주) | 4주 | 확정 |
| 인원 | 2~10명 | 해당 없음 | 확정 |

**기간을 둔 이유**: 정산표는 끝나는 날이 있어야 계산할 수 있다. 실제 벌금 스터디도 월 단위나 시험일 기준으로 끝을 정한다. 같은 멤버로 이어서 하려면 "다음 기간 시작"을 눌러 규칙을 그대로 복사한 새 기간을 연다.

**규칙 변경 (확정)**: 그룹장은 진행 중에도 규칙을 바꿀 수 있다. 바뀐 규칙은 다음 인증일부터 적용된다. 이미 판정된 날과 장부는 바뀌지 않는다. 돈 방식, 벌금 사용 방식, 탈퇴 시 돈 처리는 기간 중에 바꿀 수 없다. 이미 참여한 사람이 동의한 조건이기 때문이다.

## 3. 시간과 판정

### 3-1. 시간 기준
- 모든 시각은 한국 시간(Asia/Seoul)으로 계산한다. (확정)
- 인증 시각은 **서버가 사진을 받은 시각**이다. 휴대폰 시계는 쓰지 않는다. 휴대폰 시계는 사용자가 바꿀 수 있기 때문이다. (확정)
- AI 확인이 언제 끝나는지는 판정 시각에 영향을 주지 않는다. (확정)

### 3-2. 인증일의 경계 (매일 방식)
마감 시각이 M, 유예 시간이 G일 때:
- 인증일 D의 정상 구간: 인증일 D-1의 마감 M 이후 ~ 인증일 D의 마감 M
- 인증일 D의 지각 구간: 마감 M 이후 ~ M + G
- 지각 구간에 올린 사진은, 인증일 D에 아직 인증이 없으면 D의 지각 인증이 된다. D에 이미 인증이 있으면 다음 인증일(D+1)의 정상 인증이 된다. (확정)
- 하루에 여러 장을 올려도 판정은 하나다. 가장 이른 인증 하나만 판정에 쓴다. (확정)

예시: 마감 23:59, 유예 1시간
| 올린 시각 | 11월 27일 인증 여부 | 결과 |
|---|---|---|
| 11월 27일 22:10 | 없음 | 27일 정상 |
| 11월 28일 00:30 | 없음 | 27일 지각 |
| 11월 28일 00:30 | 이미 있음 | 28일 정상 |
| 11월 28일 01:10 | 없음 | 27일 결석, 이 사진은 28일 정상 |

### 3-3. 판정 결과
| 결과 | 조건 | 벌금 |
|---|---|---|
| 정상 | 정상 구간에 인정된 인증이 있다 | 0원 |
| 지각 | 지각 구간에만 인정된 인증이 있다 | 지각 벌금 |
| 결석 | 인정된 인증이 없다 | 결석 벌금 |
| 쉬는 날 | 마감 전에 쉬는 날을 선언했다 | 0원 |

"인정된 인증"은 AI가 통과시켰거나, 이의 제기로 인정된 사진이다.

### 3-4. 주 N회 방식
- 한 주는 월요일 첫 인증일부터 일요일 인증일까지다. (확정)
- 하루에 여러 번 인증해도 1회로 센다. (확정)
- 일요일 마감 + 유예 시각에 그 주를 판정한다. 모자란 횟수마다 결석 벌금을 매긴다. (확정)
- 주 N회 방식에는 지각이 없다. 일요일 유예 구간에 올린 인증은 그 주의 1회로 센다. (확정)
- 쉬는 날을 쓰면 그 주에 필요한 횟수가 1 줄어든다. (확정)

### 3-5. 판정이 정해지는 순서
```
인증일 진행 중
  └ 마감 + 유예 시각 도착
      → 임시 판정 (판정 작업이 자동 실행)
          → 이의 제기 가능 (24시간)
              → 확정 판정 → 장부 기록
```
- 임시 판정 시점에 AI 확인이 아직 안 끝난 사진은 "확인 중"으로 두고 일단 인정한다. 나중에 AI가 거절하면 그 시각부터 24시간 이의 제기 기간이 다시 열린다. (확정)
- 이의 제기 기간 24시간이 지나면 판정은 확정되고 장부에 기록된다. (확정)

## 4. 인증 확인과 이의 제기

### 4-1. 사진
- 앱 카메라로 찍은 사진만 올릴 수 있다. 앨범 사진은 올릴 수 없다. (확정)
- 사진에 찍은 시각을 표시한다. (확정)
- 원본 사진은 올린 지 30일 뒤에 지운다. 판정 결과, 이의 제기 이력, 장부는 남긴다. (확정)

### 4-2. AI 확인 결과
| 결과 | 뜻 | 다음 단계 |
|---|---|---|
| 통과 | 목표에 맞는 사진이다 | 인정 |
| 애매 | AI가 판단하기 어렵다 | 그룹원 확인으로 넘긴다 |
| 거절 | 목표와 관계없는 사진이다 | 인정하지 않는다. 본인이 이의 제기할 수 있다 |

### 4-3. 그룹원 확인 (확정)
"애매" 판정과 이의 제기는 같은 방식으로 처리한다.
1. 본인을 뺀 멤버들에게 사진과 함께 확인 요청 알림이 간다.
2. 본인을 뺀 멤버의 과반이 "인정"을 누르면 인정한다.
3. 과반이 "불인정"을 누르면 불인정이다.
4. 24시간 안에 과반이 모이지 않으면 그룹장이 정한다.
5. 그룹장도 정하지 않으면 **인정**한다. 억울한 벌금이 사람을 떠나게 만드는 위험이, 봐주기 위험보다 크기 때문이다.
6. 그룹장 본인의 이의 제기에서 4번 단계는 건너뛴다.

## 5. 쉬는 날과 복귀
- 쉬는 날은 그 인증일의 마감 전에만 선언할 수 있다. 마감 전이라면 취소할 수도 있다. (확정)
- 횟수는 달력 기준 한 달마다 다시 채워진다. 남은 횟수는 다음 달로 넘어가지 않는다. (확정)
- 결석한 다음 인증일에 정상이나 지각 인증을 하면 "복귀"로 표시하고 그룹에 알린다. 돈에는 영향이 없다. (확정)

## 6. 멤버의 들어오고 나가기

### 6-1. 중간 합류 (확정)
- 참여한 다음 인증일부터 판정한다.
- 보증금 방식이면 같은 금액의 보증금을 낸다. 정산 담당이 받았음을 표시한다.

### 6-2. 그룹장이 나갈 때 (확정)
- 남은 멤버 중 가장 먼저 참여한 사람이 그룹장이 된다. 정산 담당도 함께 넘어간다.
- 남은 멤버가 없으면 그룹은 끝난다.

### 6-3. 중간 탈퇴 시 돈 처리 (확정: 그룹을 만들 때 반드시 고름)
| 돈 방식 | 선택지 | 나가는 사람이 받는 돈 | 그룹에 남는 돈 |
|---|---|---|---|
| 보증금 있음 | ① 벌금 빼고 돌려주기 | 보증금 - 그동안의 벌금 | 그동안의 벌금 |
| 보증금 있음 | ② 돌려주지 않기 | 0원 | 보증금 전액 |
| 보증금 없음 | 하나뿐: 쌓인 벌금을 내고 나간다 | 해당 없음 | 그동안의 벌금 |

- 나간 사람의 이의 제기 기간이 남은 판정은 나가는 순간 확정한다. (확정)
- 그룹에 남는 돈은 다른 벌금과 똑같이 7장의 벌금 사용 방식을 따른다. (확정)
- 나간 사람은 7장의 분배 대상에서 빠진다. (확정)

## 7. 장부와 정산

### 7-1. 장부
- 확정 판정 하나마다 벌금이 0원보다 크면 장부 항목 하나를 만든다. 금액은 **그 인증일에 적용된 규칙**의 금액이다. (확정)
- 장부 항목은 고치거나 지우지 않는다. 잘못된 항목은 반대 금액 항목을 더해 바로잡는다. (확정)
- 보증금 방식에서 한 사람의 벌금 합계는 보증금을 넘지 않는다. 넘는 벌금은 0원으로 기록하고 "보증금 소진"으로 표시한다. (확정. 실제 스터디가 월 최대 벌금을 미리 받는 방식과 같다)

### 7-2. 벌금 모음
벌금 모음 = 남은 멤버의 벌금 합계 + 나간 멤버가 그룹에 남긴 돈

### 7-3. 벌금 사용 방식별 분배 (확정: 그룹이 고름)
| 방식 | 분배 |
|---|---|
| 꼬박이 몫으로 나누기 | 기간 중 결석이 0번인 멤버끼리 똑같이 나눈다. 그런 멤버가 없으면 결석 횟수가 가장 적은 멤버끼리 나눈다 (확정) |
| 공동 비용으로 쓰기 | 나누지 않는다. 정산 담당이 모음 전체를 맡아 그룹이 정한 곳에 쓴다 |
| 전원에게 똑같이 돌려주기 | 남은 멤버 전원에게 똑같이 나눈다 |

- 나누어떨어지지 않는 원 단위 나머지는 정산 담당 몫으로 남기고 정산표에 따로 적는다. (확정)

### 7-4. 정산표
돈은 모두 정산 담당을 거친다고 보고 계산한다. 멤버끼리 직접 주고받는 길은 계산하지 않는다. 그래야 "누가 누구에게" 줄이 멤버 수만큼만 생긴다. (확정)

| 돈 방식 | 멤버별 금액 | 뜻 |
|---|---|---|
| 보증금 있음 | 보증금 - 본인 벌금 + 분배 몫 | 정산 담당이 그 멤버에게 돌려줄 돈 |
| 보증금 없음 | 분배 몫 - 본인 벌금 | 양수면 정산 담당이 줄 돈, 음수면 그 멤버가 정산 담당에게 낼 돈 |

- 그룹장은 멤버마다 "정산 완료"를 표시한다. (확정)
- 기간이 끝난 날부터 알림을 보낸다. 정산이 끝나지 않은 멤버가 있으면 3일 뒤에 한 번 더 보낸다. (확정)

### 7-5. 검산한 예시

**예시 1. 보증금 2만 원, 꼬박이 몫으로 나누기, 4명, 결석 2,000원, 지각 1,000원**
| 멤버 | 결석 | 지각 | 본인 벌금 | 분배 몫 | 돌려받을 돈 |
|---|---|---|---|---|---|
| A | 0 | 0 | 0 | 5,500 | 25,500 |
| B | 1 | 2 | 4,000 | 0 | 16,000 |
| C | 3 | 0 | 6,000 | 0 | 14,000 |
| D | 0 | 1 | 1,000 | 5,500 | 24,500 |
- 벌금 모음 11,000원. 결석 0번인 A와 D가 5,500원씩 나눈다.
- 돌려받을 돈 합계 80,000원 = 보증금 합계 80,000원. 돈이 새거나 생기지 않는다.

**예시 2. 보증금 없음, 전원에게 똑같이 돌려주기, 3명이 남고 1명이 나감, 결석 2,000원**
| 멤버 | 본인 벌금 | 분배 몫 | 금액 | 뜻 |
|---|---|---|---|---|
| A | 0 | 4,666 | +4,666 | 정산 담당이 A에게 준다 |
| B | 6,000 | 4,666 | -1,334 | B가 정산 담당에게 낸다 |
| C | 4,000 | 4,666 | +666 | 정산 담당이 C에게 준다 |
| E (나감) | 4,000 | 대상 아님 | -4,000 | 나갈 때 이미 냈다 |
- 벌금 모음 14,000원(B 6,000 + C 4,000 + E 4,000)을 3명이 나눈다. 1인당 4,666원, 나머지 2원은 정산 담당 몫이다.
- 확인: 정산 담당에게 들어온 돈(B 6,000 + C 4,000 + E 4,000 = 14,000)에서 나간 돈(4,666 × 3 = 13,998)을 빼면 나머지 2원과 같다.

## 8. 늘 지켜야 할 규칙
1. 멤버 한 명의 인증일 하나에는 판정이 하나만 있다.
2. 판정 작업을 여러 번 실행해도 결과가 같다. 이미 판정한 날은 다시 만들지 않는다.
3. 확정된 장부 항목은 바뀌지 않는다.
4. 규칙 변경은 과거로 거슬러 적용되지 않는다.
5. 보증금 방식에서 돌려받을 돈의 합계는 보증금의 합계와 같다. 보증금 없음 방식에서 분배 합계와 나머지를 더하면 벌금 모음과 같다.
6. 꼬박은 돈을 받거나 보내지 않는다.

## 9. 실패와 복구
| 상황 | 처리 | 상태 |
|---|---|---|
| AI 서비스가 멈춤 | 사진은 받아 두고 "확인 중"으로 둔다. 판정은 일단 인정한다. 이의 제기 기간이 끝날 때까지 AI 결과가 없으면 그룹원 확인으로 넘긴다 | 확정 |
| 판정 작업이 실패함 | 다시 실행한다. 8장 2번 규칙 때문에 중복이 생기지 않는다 | 확정 |
| 마감 직전에 네트워크가 끊김 | 서버가 받은 시각 기준이라 늦게 도착하면 늦은 것으로 본다. 앱은 마감 30분 전부터 "지금 올려야 안전해요"라고 안내한다 | 확정 |
| 알림이 두 번 감 | 알림마다 고유 번호를 두고 같은 번호는 한 번만 보낸다 | 확정 |

## 10. 첫 버전에서 다루지 않는 것
- 그룹장 말고 다른 사람이 정산 완료를 표시하는 것 (미결정, 첫 버전에서는 그룹장만)
- 시험이나 질병 증빙으로 벌금을 면제하는 것 (쉬는 날로 대신함)
- 여러 그룹에 동시에 참여할 때의 알림 묶기 (운영 중에 붙일 기능)
- 주간 시즌 (운영 중에 붙일 기능)
