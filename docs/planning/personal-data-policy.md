# 개인정보 정책

마지막 수정: 2026-11-27
상태: 3장 보관 기간은 확정(2026-11-27). 나머지는 권장(2026-11-27, 승인 필요)
관련 문서: [회원·참여 정책](member-group-policy.md)(가입·탈퇴), [운영 정책](operations-policy.md)(공개 범위), [ADR-0003](../adr/0003-posthog-for-product-analytics.md)(PostHog)

이 문서는 꼬박이 어떤 개인정보를 받고, 누구에게 맡기고, 얼마나 보관하고, 어떻게 지우는지 정한다. 이용자에게 보여 주는 개인정보처리방침은 이 문서를 바탕으로 쓰고, 법 근거는 그때 확인한다.

## 1. 받는 정보
| 정보 | 필수 여부 | 언제 받나 | 왜 |
|---|---|---|---|
| 카카오·애플 계정 식별값 | 필수 | 로그인할 때 | 회원을 구분한다 |
| 닉네임 | 필수 | 가입할 때 | 그룹에서 서로 알아본다 |
| 프로필 사진 주소(카카오·애플 사진을 고를 때) | 선택 | 가입할 때, 설정에서 | 그룹에서 서로 알아본다 |
| 인증 사진 | 인증할 때 필수 | 인증할 때 | 판정한다 |
| 푸시 알림 토큰 | 선택(알림 권한) | 알림 권한을 허락할 때 | 알림을 보낸다 |
| 접속 기록(접속 시각, IP 주소, 기기 종류, 앱 버전) | 자동 | 앱·웹을 쓸 때 | 보안, 장애 대응 |
| 앱 사용 기록(어떤 화면을 열고 어떤 버튼을 눌렀는지) | 자동 | 앱·웹을 쓸 때 | 기능 가설을 판정한다([기능 가설](hypotheses.md)) |
| 동의 기록 | 자동 | 동의할 때 | 동의 사실을 증명한다 |
| 문의 내용 | 문의할 때 | 문의할 때 | 문의에 답한다 |

- 이메일, 실명, 전화번호, 생년월일, 위치 정보는 받지 않는다.
- 인증 사진의 위치 정보(촬영 장소 GPS)는 앱이 올리기 전에 지운다. 촬영 시각 같은 다른 사진 정보도 함께 지운다. 판정에 쓰는 시각은 서버가 받은 시각이다.

## 2. 맡기는 곳과 해외로 보내는 정보
꼬박은 개인정보를 다른 회사에 팔거나 넘기지 않는다(제3자 제공 없음). 아래 업체에 처리를 맡긴다(처리 위탁).

| 업체 | 맡기는 일 | 보내는 정보 | 서버 위치 |
|---|---|---|---|
| Oracle Cloud | 서버와 데이터베이스, 사진 저장 | 꼬박이 받는 모든 정보 | 서울 지역을 쓴다(만들 때 확인) |
| PostHog | 앱 사용 기록 분석 | 앱 사용 기록, 내부 회원 번호 | 해외(미국 또는 EU) |
| AI 사진 확인 업체 | 인증 사진이 기준에 맞는지 판단 | 인증 사진, 인증 기준 문장 | 업체 미정. 해외일 가능성이 높다 |
| Expo, 구글(FCM), 애플(APNs) | 푸시 알림 보내기 | 푸시 토큰, 알림 내용 | 해외 |
| 카카오, 애플 | 로그인 | 로그인 요청 | 각 업체 |

- 해외로 보내는 정보는 개인정보처리방침에 나라, 업체, 항목, 목적, 보관 기간을 적는다.
- PostHog와 AI 업체에는 닉네임을 보내지 않는다. 내부 회원 번호만 쓴다.
- AI 업체는 사진을 학습에 쓰지 않는 조건의 서비스를 고른다(업체를 정할 때 확인).

## 4. 지우는 방식
- 계정을 삭제하면 개인정보는 데이터베이스에서 실제로 지운다(물리 삭제). 보관 기간이 남은 기록은 익명화해서 남긴다.
- 백업은 7일 동안만 보관한다. 지운 데이터는 늦어도 7일 뒤 백업에서도 사라진다.
- 인증 사진 파기는 매일 한 번 돌아가는 작업이 처리한다.

## 5. 기록(로그)에 대한 원칙
- 서버 로그와 오류 기록에는 닉네임, 사진 주소, 카카오·애플 식별값을 쓰지 않는다. 내부 회원 번호만 쓴다.
- 운영 데이터를 개발이나 테스트에 쓰지 않는다. 테스트는 가짜 데이터로 한다.
- 운영자가 회원 정보를 볼 때는 이유를 적고, 본 기록이 운영 기록으로 남는다.

## 6. 본인이 요청할 때
- 열람, 정정, 삭제, 처리 정지 요청은 앱 안 문의하기(계정·로그인)로 받는다.
- 10일 안에 처리한다(개인정보보호법 기준, 법 확인 필요).
- 닉네임 정정과 계정 삭제는 앱 안에서 바로 할 수 있다.
- 내 기록 내려받기 기능은 첫 버전에 없다. 요청하면 운영자가 장부·정산표·판정 기록을 파일로 만들어 10일 안에 보낸다.

## 7. 수사기관이나 법원이 요청할 때
- 영장, 법원 명령처럼 법적 근거가 있는 요청에만 응한다.
- 요청서에 적힌 범위만 준다.
- 법이 막지 않으면 해당 회원에게 요청 사실을 알린다.
- 요청과 제공 내역은 운영 기록으로 남긴다.
